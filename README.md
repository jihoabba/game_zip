# 네모 빵집 · NEMO BAKERY

네모 빌리지의 따뜻한 도트 감성으로 만든 2D 빵집 게임. 기존 Sweet Recipe 캐릭터·가구·디저트 어셋을 사용했습니다.

**[게임 플레이](https://nemo-bakery-dh.cuty-jiho.chatgpt.site)** · 현재 플레이 링크는 소유자의 ChatGPT 로그인이 필요합니다.

## 게임 방식

- 레시피 5종: 블루베리 롤, 레몬 파운드, 딸기 도넛, 버터 슈, 초코 까눌레
- 레시피 선택 → 반죽 → 오븐에 넣기 → 완성된 빵 꺼내기 → 손님에게 판매
- 하루 영업 3분, 빠른 판매 팁과 연속 판매 보너스
- 영업 정산 후 오븐 추가 및 제빵 속도 업그레이드
- 날짜·보유금·업그레이드·최고 매출은 현재 브라우저에 자동 저장
- 진행 중인 하루는 저장되지 않습니다. 탭을 벗어나면 자동 일시정지됩니다.

## 실행

별도 빌드 없이 `dist/`를 정적 웹 서버로 제공하면 됩니다. Phaser와 이미지가 모두 포함되어 있어 실행 시 CDN에 의존하지 않습니다.

Python 3이 설치되어 있다면:

```sh
git clone https://github.com/jihoabba/game_zip.git
cd game_zip
python3 -m http.server 8000 --directory dist
```

브라우저에서 <http://localhost:8000>을 엽니다. JavaScript 모듈을 사용하므로 `index.html`을 파일로 직접 열지 말고 웹 서버로 실행하세요.

## 조작

| 조작 | 기능 |
| --- | --- |
| 클릭 / 터치 | 바닥으로 이동, 가구에서 작업 |
| 방향키 / WASD | 이동 |
| E | 가까운 가구 사용 |
| 1 / 2 / 3 | 반죽대 / 오븐 / 판매대로 이동 후 작업 |
| 레시피 / 주문표 | 레시피 선택 및 반죽대로 이동 |
| 화면 위 Ⅱ | 일시정지 |
| 화면 위 ♪ | 효과음 켜기 / 끄기 |

오븐에서 빵이 완성되면 다시 눌러 꺼내세요. 완성 후 18초가 지나면 빵이 탑니다.

## 코드 구조

| 경로 | 내용 |
| --- | --- |
| `dist/index.html` | 게임 화면 |

| `dist/js/scene.js` | Phaser 렌더링·캐릭터 이동·어셋 처리 |

| `dist/assets/` | 캐릭터·가구·소품 시트와 Phaser |
| `tests/game.test.js` | 게임 로직 테스트 |

## 테스트

Node.js 18 이상에서 실행합니다. Node 내장 테스트 러너를 사용하므로 의존성 설치 없이 실행할 수 있습니다.

```sh
npm test
```

제빵부터 판매까지의 흐름, 일시정지, 빵 타기, 꽉 찬 오븐, 일일 정산·업그레이드·저장, 주문 만료, 작업대 경로 도달을 검사합니다.
